# 模板：本地信息块

> 用途：在 git 忽略的 `本地信息/` 中登记环境、资源或账号。AI 只能通过 `scripts/private.sh` 操作这些文件。
> 一行一个信息；值只写顶格 `标签：值` 行。新增条目时只加空标签，真实值由用户本人填写。

```markdown
# 【项目名 · 信息类型】

项目：项目名
环境：本地开发 / 测试 / 生产
标签1：
标签2：
来源/依据：可选的编号或受控渠道指针
```

- 多环境就分段：`## 本地开发` / `## 测试` / `## 生产`，每段同样一行一个信息。
- 查看：`bash scripts/private.sh view <文件名>`；输出会遮蔽所有非空值。
- 追加空标签：`bash scripts/private.sh add <文件名> <标签> [标签...]`。
- 文件名只能是 `本地信息/` 下的普通文件名，不能含路径分隔符。
