# 模板：登记一条决策

> 用法：先取号（`bash scripts/next-id.sh D`），再在 `30_合规与决策/决策记录.md` 表格追加一行。复杂决策可在该行下方展开小节，套用以下结构。

## D-x ｜ 决策标题

- **日期**：YYYY-MM-DD
- **决策内容**：（一句话说清拍板了什么）
- **依据/背景**：（为什么这样定；引用的材料、对话、数据）
- **操作人**：（AI / 用户 / AI·用户拍板——事后查"这条是谁拍的板"全靠它）
- **影响范围**：（哪些文件/流程要跟着改）
- **关联编号**：（由哪个 Q 闭环而来、影响哪些 R/E）
